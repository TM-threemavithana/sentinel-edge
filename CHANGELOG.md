## [1.0.0] - 2026-09-02

### Added

- Cloudflare-native AI and API security gateway
- Authenticated operations console with TOTP MFA and role-based access
- Deterministic inspection, ordered policies, tenant rate limits, and audit events
- Protected Groq chatbot demonstration and production deployment workflows
- DNS-aware SSRF protection for registered and forwarded upstreams
- Automated secret-history scanning, Semgrep CE analysis, SBOM generation, and DAST
- Coverage gates, browser journeys, and automated accessibility checks
- Safe local setup, deployment validation, integration examples, and troubleshooting documentation
- Public, credential-free product showcase
- Contributor guidance, issue templates, and release documentation
- Browser isolation, content-security, transport, and private-cache response headers

### Changed

- Improved console color contrast, keyboard navigation, form semantics, and modal scrolling
- CI now uses a frozen lockfile and verifies coverage, configuration, builds, and browser tests
